# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-05-29

### Added

- Initial Firefox extension release for exporting Overleaf review comments.
- CSV export flow from the popup UI.
- XLSX export flow from the popup UI.
- Context and highlight extraction pipeline from Overleaf editor and review panel.
- AMO submission checklist and privacy policy documentation.

### Changed

- README expanded with usage, output schema, troubleshooting, and project documentation links.
- Added repository-level contributing, testing, architecture, and FAQ guides.

### Notes

- Current release targets Firefox 140.0 and newer.
- Extraction relies on Overleaf DOM conventions and may require maintenance if upstream UI changes.
